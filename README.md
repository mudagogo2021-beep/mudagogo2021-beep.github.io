# mudagogo2021-beep.github.io

GitHub Pages user site for Mudasir Khan (Tuan Muda, @youngsirmuda).

This repo exists so `robots.txt` and `sitemap.xml` live at the domain root,
which Google actually reads. Project sites (`/tuanmuda/`, `/atlas-test/`, and so on) stay in their own repos.

Private paths are disallowed in `robots.txt` and are not listed in the sitemap: `/lena/`, `/tuanmuda/bot-office/`, `/tuanmuda/snap-nyc/`.
